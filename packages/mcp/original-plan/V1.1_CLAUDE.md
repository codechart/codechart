# cochart-mcp

MCP server connecting LLM clients to diagram UI via WebSocket.

## Components

- **UI**: localhost:14 - displays diagrams
- **API**: localhost:20 - processes data
- **MCP Server**: bridges LLM ↔ UI via WebSocket (port 8765)
- **Example App**: simple todo app for testing

## Agents

| Command | Role |
|---------|------|
| /start | Begin project |
| /orchestrate | Team Leader - coordinates |
| /architect | Design decisions |
| /coder | Implementation |
| /unitester | Unit tests |
| /qa | E2E + verification |

## Key Files

- `PLAN.md` - phases and tasks
- `leader.status.md` - TL progress + todo list
- `architect.status.md` - design decisions log
- `coder.status.md` - implementation log
- `unitester.status.md` - test results log
- `qa.status.md` - verification log
- `TESTS.md` - QA checklist

## MCP Tools

- validate_json, send_to_ui, add_to_diagram
- get_diagram_json, get_diagram_image, save_image
- get_selected_nodes, save_diagram, load_diagram
