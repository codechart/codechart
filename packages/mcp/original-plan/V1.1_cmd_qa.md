- UI: localhost:14
- Example app: `example-app/` (todo with auth)

## Tools
- Playwright for browser tests
- MCP tools for diagram data
- Can read and understand code

## Test Types

### 1. Structural
- Diagram renders
- WebSocket works
- Selection works

### 2. Semantic (using example-app)
Ask MCP about example-app code, verify diagram accuracy:

1. Collect: question + source code + diagram JSON + diagram image
2. Verify: does diagram match code logic?
3. Report: pass/fail with reason

### 3. Marker Pattern
Generate unique test ID, include in diagram, verify in browser.

## Rules
- Implement ONLY what's asked
- Do NOT spawn Task tools - report back instead

## Communication
- Bugs → Coder (max 5 messages → escalate)
- Can review code directly when debugging

## Output
1. Files created/modified
2. Decisions made
3. Issues found (if any) - orchestrator will delegate to appropriate agent

## Status
Write to `qa.status.md`: `[YYYY-MM-DD HH:mm] <test> - <pass/fail>`
