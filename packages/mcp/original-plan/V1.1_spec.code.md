# cochart-mcp Spec

## Server Config

```typescript
const server = new McpServer({
  name: "cochart-mcp",
  version: "1.0.0",
  instructions: `
You help create and analyze diagrams.

WORKFLOW:
1. Read: get_diagram_json first
2. Decide: need image? (only for spatial questions)
3. Act: create/modify/analyze
4. Validate: always before send_to_ui

If unclear, ask user.
`
});
```

## Tools

| Tool | Purpose |
|------|---------|
| validate_json | Check schema, return errors |
| send_to_ui | Push diagram (replaces) |
| add_to_diagram | Merge nodes/edges |
| get_diagram_json | Get current state |
| get_diagram_image | Get screenshot (512px max) |
| save_image | Save screenshot to file |
| get_selected_nodes | Get user selection |
| save_diagram | Write JSON to file |
| load_diagram | Read and display |

## Schemas (Zod)

```typescript
const NodeSchema = z.object({
  id: z.string(),
  type: z.string(),
  label: z.string(),
  x: z.number(),
  y: z.number(),
});

const EdgeSchema = z.object({
  source: z.string(),
  target: z.string(),
  label: z.string().optional(),
});

const DiagramSchema = z.object({
  nodes: z.array(NodeSchema),
  edges: z.array(EdgeSchema),
});
```

    const msg = JSON.parse(data);

## WebSocket Messages

### MCP → UI
```typescript
{ type: "render_diagram", payload: DiagramData }
{ type: "request_diagram_json", requestId: string }
{ type: "request_screenshot", requestId: string, maxSize: number }
{ type: "request_selected_nodes", requestId: string }
```

### UI → MCP
```typescript
{ type: "diagram_json_response", requestId: string, data: DiagramData }
{ type: "screenshot_response", requestId: string, base64: string, mimeType: string }
{ type: "selection_response", requestId: string, selectedNodes: string[] }
{ type: "selection_changed", selectedNodes: string[] }
```

## MCP Prompts

```typescript
server.prompt("create_diagram", { description: z.string() }, ({ description }) => ({
  messages: [{
    role: "user",
    content: {
      type: "text",
      text: `Create diagram for: ${description}

1. Generate JSON with nodes and edges
2. Call validate_json
3. Fix errors if any
4. Call send_to_ui`
    }
  }]
}));
```
