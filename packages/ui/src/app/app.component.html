  • Open a file using the "Open a File" button. Click the file node to see file content

  • Select direction of new added nodes, search pattern by language, in same menu
  • Files are color coded. Nodes have color nodes connected to them, and also visible in legend on top of diagram

  • Add remark and to-do nodes by right clicking on diagram. You can set text of to-do nodes using text editor.
  • Delete nodes by pressing 'delete' or 'backspace' buttons.
  • Multi select nodes by pressing ctrl key and clicking nodes, or pressing 'ctrl' + right click and drag
  • Save and load from and to JSON file or Archiver by pressing the waffer icon on the top right
  • Sync diagram with current content of files. Conflicts will be visible as nodes
  • You can edit text in text editor and save to file using the text editor options menu
